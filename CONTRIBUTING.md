# Contributing

Contributions welcome: lessons, reproducible labs, defensive examples, synthetic datasets, diagrams, and runbooks.

Checklist:
- Explain objective, audience, scope, and prerequisites.
- Use synthetic data and safe local targets.
- Include reproducible setup, expected results, and cleanup.
- Include remediation and regression verification.
- Avoid real secrets, personal data, and unlicensed content.
- Link authoritative references and note version-sensitive behavior.
