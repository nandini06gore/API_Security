# Learning Path

**Beginner:** HTTP, API styles, JSON, API lifecycle, local development, and basic REST API construction.

**Intermediate:** authentication, authorization, input validation, secure errors, threat modeling, OWASP API risks, and safe local testing.

**Advanced:** API assessment, business logic, GraphQL, webhooks, gateways, cloud-native deployments, and CI/CD security.

**Operations / SRE:** structured logs, metrics, traces, health checks, alerting, capacity, incident triage, and post-incident reviews.

**Expert:** automated inventory, zero-trust service communication, complex abuse investigation, and enterprise API security programs.

## Practice loop
Understand the concept → map trust boundaries → reproduce safely → collect sanitized evidence → implement defense → add regression tests → monitor → document.
