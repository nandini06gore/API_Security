# API Security Engineering Lab

A hands-on, beginner-to-advanced learning repository for **Cybersecurity, Developers, DevSecOps, Platform Engineering, and IT Operations / SRE**.

Learn to design, build, test, secure, deploy, monitor, and investigate APIs. Every subject connects three perspectives:
1. **Cybersecurity:** threats, authorized testing, assessment, detection, and incident response.
2. **Development / DevSecOps:** secure implementation, automated tests, CI/CD integration, and security gates.
3. **Operations / SRE:** gateways, TLS, secrets, logging, monitoring, rate limiting, availability, and troubleshooting.

## Learning path

| Stage | Modules | Focus |
|---|---|---|
| Foundations | 00–02 | API concepts, development, identity and access |
| Security testing | 03–06 | Security controls, OWASP risks, testing and assessment |
| Platform security | 07–09 | Gateways, CI/CD, cloud and Kubernetes |
| Operations | 10–11 | Observability, detection and incident response |
| Engineering mastery | 12–14 | Automation, advanced protocols and capstones |

## Repository map
- `00`–`14`: progressive modules and topic folders
- `labs/`: practical lab briefs
- `vulnerable-apis/`: intentionally insecure local training-target scaffold
- `secure-api-examples/`: defensive implementation examples
- `sample-data/`: synthetic logs and OpenAPI examples
- `scripts/`: Python, Bash and PowerShell utilities
- `templates/`: reusable lab, assessment and incident templates

## Quick start
1. Read `ROADMAP.md`, `LEARNING-PATH.md`, and `SECURITY.md`.
2. Start with `00-api-security-foundations`.
3. Use only systems you own or have explicit permission to test.
4. Keep vulnerable targets bound to localhost or an isolated lab network.
5. Record findings, evidence, remediation, and verification.

This is an initial scaffold: topic folders are ready for progressive lesson development, not all complete lessons yet.
