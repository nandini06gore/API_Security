# LAB-011: Add structured audit logging

**Audience:** Operations / Security

## Objective
Record security events while excluding credentials and sensitive payloads.

## Scope and safety
Use only the local training target or an explicitly authorized environment. Do not use real credentials, personal data, or production systems.

## Prerequisites
- Read the related module.
- Record tool and runtime versions.
- Confirm target address and scope.

## Procedure
1. Prepare the lab and synthetic test data.
2. Capture baseline behavior.
3. Execute the exercise and record sanitized evidence.
4. Explain the security or operational impact.
5. Apply a defensive control.
6. Repeat the test and record verification.

## Deliverables
Commands or test steps; sanitized evidence; finding or observation; remediation and verification; cleanup notes.

## Cleanup
Stop local services and remove temporary test data and credentials.
